# Frontend - Sistema de Reservas

Frontend MVC en TypeScript sin frameworks.

## Requisitos
- Backend en `http://localhost:3000`
- Node.js instalado

## Build
```bash
npx tsc -p frontend/tsconfig.json
```

## Servidor local
```bash
node frontend/dev-server.js
```

Luego abre `http://localhost:5173` en el navegador.
